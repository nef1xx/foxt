# BRATKI 2026

Сайт локальной премии друзей БРАТКИ INSIDE. Космический редакционный стиль по референсам пользователя: ночное небо, холодное свечение, тонкие орбиты, крупная типографика с каллиграфическими акцентами. Девять оригинальных изображений: главный экран и восемь номинаций. Видео не используется.

## Запуск

Требуется Node.js 22+. Для проверок и локальной базы выполнить `npm ci`. Публичный сайт не загружает npm-зависимости.

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173`. Шорт-лист хранится только в браузере, его можно скачать текстовым файлом. Это черновик, не голосование и не заявка организаторам.

```sh
npm run check
npm run build
```

Готовая статика находится в `dist/`. Все изображения и шрифты локальные; сайт не зависит от CDN. Относительные пути поддерживают адреса GitHub Pages вида `/repository/`. Старые янтарные изображения и WebM исключены из сборки.

## GitHub Pages

1. Загрузить проект в свой GitHub-репозиторий в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**.
3. Выполнить push или запустить workflow **Deploy BRATKI to GitHub Pages** вручную во вкладке Actions.

Workflow `.github/workflows/pages.yml` проверяет JavaScript, собирает только публичные файлы в `dist/` и публикует их. Исходный Telegram JSON в проект не копируется и в публикацию не попадает. Если основная ветка называется иначе, изменить `branches` в workflow.

Репозиторий проекта: [nef1xx/foxt](https://github.com/nef1xx/foxt). Адрес GitHub Pages: [nef1xx.github.io/foxt](https://nef1xx.github.io/foxt/). Обновления из ветки `main` публикуются workflow автоматически.

## Голосование

Голосование работает прямо на сайте по нику и личному коду. `vote.html` — участнику, `admin.html` — организатору. PostgreSQL/Supabase проверяет код и принимает один целый бюллетень атомарно. В панели видна явка без индивидуального выбора; итоги открываются после закрытия и отдельной публикации.

Пока `voting-config.js` не содержит подключения к Supabase, страницы показывают подготовку и не принимают голоса. Настоящие кандидаты и две дополнительные номинации задаются организатором перед открытием. Порядок подключения, выдачи кодов, локальной проверки и границы приватности — в [VOTING.md](VOTING.md).

## Медиа и доступность

Девять оригинальных изображений созданы встроенным imagegen и сохранены в `assets/cosmic/` в WebP. Отдельная иллюстрация предусмотрена для каждой номинации. Полный набор промптов, список файлов и лицензии шрифтов перечислены в [ASSETS.md](ASSETS.md).

Анимация выполнена Canvas 2D, CSS и JavaScript: мерцающие звёзды, редкие кометы, мягкое движение статичного фона, бегущая строка, появление секций и наклон карточек. Кнопка «Анимация» останавливает непрерывные эффекты; `prefers-reduced-motion` и `saveData` отключают их по умолчанию. Рендер Canvas ограничен примерно 30 кадрами в секунду и останавливается в скрытой вкладке. Без JavaScript текстовые разделы остаются видимыми.

Формы имеют подписи, диалоги используют нативное управление фокусом и Escape, FAQ — нативные details/summary. Пользовательские имена и описания в шорт-листе вставляются как текст. Старый генератор видео сохранён в истории проекта и не доступен через dev-сервер или опубликованный сайт.
